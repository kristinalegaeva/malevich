# Казимир Малевич в Русском музее

React-приложение на Vite.

Рекомендуется Node.js 24. В GitHub Actions используется та же версия.

## Запуск

```sh
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://127.0.0.1:5173). Открывать `index.html` напрямую больше не нужно.

## Сборка

```sh
npm run build
npm run preview
```

Готовое приложение находится в `dist`.

Проверка исходных данных и файлов: `npm run check`.

## GitHub и GitHub Pages

Создайте на GitHub пустой публичный репозиторий `malevich` без автоматически созданного README. Затем выполните в папке проекта, заменив `USERNAME` на свой логин:

```sh
git init
git add .
git commit -m "Initial React app"
git branch -M main
git remote add origin https://github.com/USERNAME/malevich.git
git push -u origin main
```

В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. В **Actions → Deploy to GitHub Pages** запустите **Run workflow**, если первый запуск уже завершился ошибкой до включения Pages.

Workflow `.github/workflows/deploy.yml` сам установит зависимости через `npm ci`, проверит файлы, соберёт приложение и опубликует `dist`. Следующие изменения деплоятся автоматически после push в `main`. Адрес будет `https://USERNAME.github.io/malevich/`; точный адрес появится в результате workflow.

Загружайте исходники через Git, а не папку `dist` вручную. `.gitignore` исключает `node_modules`, `dist`, служебные копии в `public` и неиспользуемые картины с префиксом `0`. Исходные картины с префиксом `1` и папка `assets` нужны для сборки в GitHub Actions. Оригиналы остальных картин сохранены локально.

В каталоге 184 картины, около 237 МБ. Исходники SVG и шрифтов хранятся один раз в `assets`; копии создаются при сборке. Относительная база Vite и единая функция `assetUrl` позволяют открывать сайт в подпапке любого имени.

Официальные инструкции: [Vite — GitHub Pages](https://vite.dev/guide/static-deploy#github-pages), [GitHub — источник публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Структура

- `src/App.jsx` — композиция страницы и состояние открытой картины.
- `src/components/Narrative.jsx` — композиция шапки и текстовых секций.
- `src/components/Story.jsx`, `StoryParagraph.jsx`, `Bridge.jsx` — компоненты текстовых блоков с данными через props.
- `src/data/story.js` — заголовки и абзацы как цельные строки с автоматическим переносом по ширине.
- `src/utils/typography.js` — Typograf: неразрывные пробелы после коротких предлогов и союзов, перед частицами и коротким последним словом. Обработка выполняется при загрузке данных без вставки HTML.
- `src/components/Gallery.jsx` — выбранная картина, кнопки, клавиатура и колесо.
- `src/components/Timeline.jsx` — точки, дата, название картины и периоды.
- `src/components/Lightbox.jsx` — диалог, масштабирование и перемещение изображения.
- `src/data/artworks.js` — каталог 184 используемых картин из имён файлов.
- `src/data/catalog.js` — предварительное распределение картин по периодам.
- `src/utils/assetUrl.js` — пути к файлам с учётом подпапки сайта и специальных символов.
- `src/styles.css` — стили, шрифты и мобильные правила.
- `scripts/sync-assets.mjs` — подготовка статичных файлов для Vite.
- `scripts/check-project.mjs` — проверка каталога, изображений, SVG и шрифтов.

Исходные `assets` и `Малевич` сохраняются на месте. Перед запуском и сборкой SVG, шрифты и картины с префиксом `1 — ` автоматически копируются в `public`; изменённые исходники обновляются при следующем запуске команды. Генерируемые папки не включаются в Git.

Редактируйте SVG и шрифты только в **корневой папке `assets`**. `public/assets` — служебная копия для Vite, `dist` — результат сборки. В `assets/header.svg` находится десктопная шапка, в `assets/header phone.svg` — телефонная; браузер выбирает их через `picture` на границе 760 px. После добавления файлов перезапустите `npm run dev` или выполните `npm run build`.

На телефоне вертикальная линия скрыта, текст истории выровнен вправо. Подложка применяется только к строкам через `box-decoration-break: clone`, а не ко всему блоку. Цвета выделения и контрастного текста заданы в `src/data/story.js` и соответствуют пяти кругам исходного SVG.

Текст Story удерживается по вертикальному центру окна через CSS sticky. Один таймлайн GSAP ScrollTrigger последовательно проявляет параграф, оставляет его для чтения и скрывает перед следующим. Меняется только прозрачность. StoryParagraph отвечает за разметку, анимация и её очистка находятся в Story. При уменьшении движения в настройках системы текст отображается обычным списком.

SVG с кругами не изменён: ширина 691 px, автоматическая высота 3455 px. Круги находятся вне закреплённого слоя и прокручиваются обычным образом. Шапка расположена под кругами по слоям. Helvetica Neue подключена локально.

Галерея занимает 88% окна и не блокирует прокрутку страницы. Дата находится у активной точки, название — под таймлайном. Названия периодов разделены `/`, текущий период выделен красным.

Полноэкранный просмотр: колесо, двойной щелчок и жест двумя пальцами меняют масштаб; увеличенную картину можно перетаскивать. Escape и крестик закрывают просмотр. Обработчики внешних событий снимаются в cleanup-функциях React.

Названия и годы получены из имён файлов. Группировка по периодам предварительная; пограничные произведения требуют кураторской проверки. Документ Figma не изменялся, публикация не выполнялась.
