# Казимир Малевич в Русском музее

Сайт о Малевиче по мотивам [мультимедийного проекта Русского музея](https://rusmuseumvrm.ru/data/mediateka/kazimir_malevich/index.php?lang=ru). Сначала идёт короткая история с падающими фигурами, затем — хронология работ. В галерее можно искать по названию или году и открывать работы на весь экран. На телефоне верхнее меню открывается, если потянуть страницу вниз у верхнего края.

## Запуск

Подойдёт Node.js 24, он же используется при публикации.

```sh
npm ci
npm run dev
```

Откройте адрес из терминала. Проект собран на React и Vite, анимация при прокрутке сделана на GSAP ScrollTrigger.

## Где что менять

- Текст истории — в [Story.jsx](src/components/Story.jsx).
- Стартовые позиции фигур для телефона и компьютера — в [storyFigures.js](src/data/storyFigures.js), их движение — в [StorySequence.jsx](src/components/StorySequence.jsx).
- Изображения шапки и шрифты — в [assets](assets). Папка [Малевич](Малевич) содержит исходные JPG, а названия, годы и пути к ним хранятся в [artworks.js](src/data/artworks.js).
- Стили — в [src/styles](src/styles). У истории, галереи и верхнего меню свои файлы.

Перед запуском и сборкой нужные изображения и шрифты копируются из исходных папок в `public`.

## Сборка и публикация

```sh
npm run check
npm run build
npm run preview
```

`check` проверяет каталог и наличие файлов. `preview` открывает результат сборки из `dist` локально. После изменений в `main` сайт публикует [workflow GitHub Pages](.github/workflows/deploy.yml).
